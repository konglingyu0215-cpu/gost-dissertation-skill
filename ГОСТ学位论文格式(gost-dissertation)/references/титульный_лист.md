# 扉页（титульный лист）：要素与排版

> **本文件的证据分两层，用法不同，不要混。**
>
> **第一层：标准条文。** 只有「写哪几项」有规定。ГОСТ Р 7.0.11-2011 §5.1 整节仅三款：5.1.1 扉页是论文第 1 页兼检索信息源；5.1.2 列出信息项；5.1.3 非俄语论文须附俄语扉页。**没有任何一款规定位置、字号、行距、对齐、块间空行。**
>
> **第二层：范本惯例。** 下面的位置、字号、对齐、空行，来自五篇俄罗斯教育学（5.8.2）答辩论文的扉页实测，**是惯例，不是标准条文**。你自己的学校若有模板，以学校模板为准。
>
> 实测样本：五篇 A4 论文的第 1 页，用 PDF 文字块坐标反推。样本中的人名、题目、单位已全部换成占位符，本文件不保留任何真实个人信息。

## 1  要素清单（标准依据：ГОСТ Р 7.0.11-2011 §5.1.2）

按自上而下顺序，共八项：

| # | 要素 | 俄语原文措辞 |
|---|---|---|
| 1 | 上级机关与学校全称 | наименование организации（可上溯至部委） |
| 2 | 手稿标识 | «На правах рукописи» |
| 3 | 作者姓名 | фамилия, имя, отчество диссертанта |
| 4 | 论文题目 | название диссертации |
| 5 | 专业代码与名称 | шифр и наименование специальности |
| 6 | 学位与学科门类 | искомая учёная степень и отрасль науки |
| 7 | 导师姓名、学位、职称 | фамилия, имя, отчество научного руководителя, учёная степень, учёное звание |
| 8 | 完成地点与年份 | место и год написания |

「论文题目」在全文中出现三次（扉页、目录、正文标题），必须**逐字一致**。

## 2  五篇范本的排版惯例

### 2.1 字号：全文统一，不分层

五篇**全部**在 13.9–14.0 pt 之间浮动（即 14 pt，四号），**没有一篇**给题目放大、给其余信息缩小。

> 常见错误：题目 16 pt、作者 14 pt、其余 12 pt。这是中文论文的做法，俄方范本里看不到。

### 2.2 各块的位置（占页高的百分比）

以 A4（842 pt 高）为基准，五篇的中位值与取值范围：

| 块 | 中位 y | 取值范围 | 水平对齐 |
|---|---|---|---|
| 抬头首行 | 6.5 % | 6.5 – 8.6 % | 居中 |
| 抬头末行 | 12.3 % | 11.4 – 15.2 % | 居中 |
| «На правах рукописи» | 19.9 % | 14.3 – 20.9 % | **右对齐** |
| 作者姓名 | 28.1 % | 23.0 – 31.4 % | 居中，**加粗** |
| 题目首行 | 35.2 % | 31.6 – 37.1 % | 居中，**加粗** |
| 题目末行 | 40.2 % | 36.7 – 41.0 % | 居中，**加粗** |
| 专业首行 | 46.7 % | 43.0 – 46.7 % | 居中 |
| 专业末行 | 51.7 % | 48.7 – 52.4 % | 居中 |
| «Диссертация…» 首行 | 57.4 % | 54.3 – 58.1 % | 居中 |
| «…кандидата наук» 末行 | 63.2 % | 56.3 – 63.9 % | 居中 |
| 导师块首行 | 71.7 % | 65.8 – 74.2 % | **右对齐** |
| 导师姓名 | 74.6 % | 69.6 – 80.2 % | **右对齐，加粗** |
| 地点 | 86.0 % | 84.9 – 86.9 % | 居中 |
| 年份 | 88.9 % | 86.9 – 89.7 % | 居中 |

**两条最容易做错的：**

1. **«На правах рукописи» 靠右**，不是居中；它的右边界与右侧正文边界平齐（实例 x1 = 556–570 pt，页面宽 595 pt）。
2. **导师块整体靠右**（五篇一致）：三个信息点全部右对齐，右边界与 «На правах рукописи» 同一条竖线，只有姓名加粗。

### 2.3 块间空行

按 14 pt + 1.5 倍行距（单行 24.15 pt ≈ 页高的 2.87 %）折算，五篇的空行分配是：

| 之间 | 空行数 |
|---|---|
| 抬头 → «На правах рукописи» | 1 |
| → 作者姓名 | 2 |
| → 题目 | 1 |
| → 专业 | 1 |
| → «Диссертация…» | 1 |
| → 导师块 | 1 |
| → 地点 | 3 |
| 地点 → 年份 | 0（紧接下一行） |

合计文字 20 行 + 空行 10 行 = 30 行，正好从 6.5 % 铺到 89.7 %。

> **易犯的错**：块间空行给少（每处只空 1 行），整块内容挤在页面上半部，到 62 % 就结束，下半页留一大片空白。范本是铺满到底的。

### 2.4 抬头部分的实际写法

无统一格式，实测四种写法都用过。最常见的是三到四行：

```
МИНИСТЕРСТВО ПРОСВЕЩЕНИЯ РОССИЙСКОЙ ФЕДЕРАЦИИ
Федеральное государственное бюджетное образовательное учреждение
высшего образования
«<Название университета>»
```

也有省掉部委行的（两行）与把 «высшего образования» 并入上一行的（三行）。**以学校官方模板为准**，没有模板时任选一种，不要自创第五种。

### 2.5 专业行与学位行的常见写法

```
Шифр и наименование специальности:
5.8.2 — Теория и методика обучения и воспитания
(по областям и уровням образования)
```

```
Диссертация
на соискание ученой степени
кандидата педагогических наук
```

两种都会出现：`Шифр и наименование специальности` / `Специальность` / `Научная специальность`；`Диссертация` 单独一行或与 `на соискание…` 同行。**同一篇内部保持一致即可**。

### 2.6 题目大小写

两篇全大写，一篇正常大小写（首词与专名大写）。都合规，**全文统一**就行。

### 2.7 页码

扉页算第 1 页，**不标页码**（ГОСТ Р 7.0.11-2011 §5.3.8）。第 2 页起标「2」。

Word 实现：页眉插入居中 PAGE 域，再勾选「首页不同」并清空首页页眉。

## 3  生成步骤（python-docx）

1. **先删后插，且在同一个 Document 对象里操作。** 重新 `Document(path)` 会读到未保存的旧内容，`insert_paragraph_before` 与 `addnext` 混用容易把顺序搞乱。
   ```python
   d = Document(P)
   i0 = next(i for i, p in enumerate(d.paragraphs) if p.text.strip() == 'СОДЕРЖАНИЕ')
   for p in d.paragraphs[:i0]:
       p._element.getparent().remove(p._element)
   anchor = next(p for p in d.paragraphs if p.text.strip() == 'СОДЕРЖАНИЕ')._p
   ...
   p = d.add_paragraph(); anchor.addprevious(p._p)   # 顺序插在目录前
   ```
2. 每个新段落显式设 `first_line_indent = 0`、`space_before = after = 0`、`line_spacing = 1.5`——否则会继承正文的首行缩进。
3. 中俄混排时（例如中文姓名 + 俄语姓名），西里尔字母要用 Times New Roman，不要落到中文字体上；否则字母间距会被拉得很开：
   ```python
   r.font.name = 'Times New Roman'
   rPr.find(qn('w:rFonts')).set(qn('w:eastAsia'), '宋体')
   ```
4. 扉页最后一段接一个分页符，或给目录首段设 `page_break_before = True`。

## 4  自查清单

- [ ] 八项要素齐全，顺序自上而下
- [ ] 全文同一字号（14 pt），无放大缩小
- [ ] «На правах рукописи» 靠右，无人居中
- [ ] 作者姓名加粗
- [ ] 题目加粗，且与目录、正文标题逐字一致
- [ ] 导师块三行全部靠右，姓名加粗
- [ ] 地点与年份在页底（约 86 % 与 89 %），不是跟在导师后面就结束
- [ ] 扉页无页码，第 2 页显示「2」
- [ ] 扉页本身无页眉
- [ ] 无占位符残留（`(Фамилия И. О. — заполнить)` 一类）在交稿前全部替换

## 5  与标准的边界

| 项 | 依据 |
|---|---|
| 八项要素 | ГОСТ Р 7.0.11-2011 §5.1.2 |
| 扉页算第 1 页不标号 | §5.3.8 |
| 版式参数（A4、1.5 倍、12—14 pt、页边距） | §5.3.6、§5.3.7 |
| 扉页无页眉 | 由「不标页码」推出，非明文 |
| **位置、字号分层、对齐、空行、加粗** | **范本惯例，无条文** |
