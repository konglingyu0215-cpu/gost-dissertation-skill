# gost-academic

DSH（DeepSeek Harness）技能：按俄罗斯国家标准（ГОСТ Р 7.0.100-2018 / ГОСТ Р 7.0.11-2011 / ГОСТ Р 7.0.5）排版学位论文。

覆盖：论文结构、导言八要素、目录、版式参数、章节标题、插图表格公式、附录、缩写清单、
文中引用三格式、文献表著录、摘要（автореферат）、科学报告式论文、答辩材料组织。

## 安装
1. 把 `ГОСТ学术规范(gost-academic)` 文件夹复制到 `C:\Users\<用户名>\.dsh\skills\`
2. 重启 DSH / 新开会话即可

## 使用
直接说「按 ГОСТ 排版这篇论文」「检查参考文献是否符合 ГОСТ」即可触发，无需命令。
