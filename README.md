# gost-dissertation

**按俄罗斯国家标准排版学位论文的 DSH 技能**（кандидатская / докторская диссертация）

中国人写俄语学位论文，最难的一关往往不是语言，是格式——页边距差 5 毫米、目录少个点线、导言少两项，都可能被打回。这个技能把 ГОСТ Р 7.0.11-2011 里管学位论文的那几节逐条拆成可执行的参数与检查项，让格式这件事不靠猜。

---

## 它管什么

### 一、结构

- 手稿式学位论文的完整组成（扉页 / 目录 / 正文 / 缩写清单 / 术语表 / 文献表 / 插图材料清单 / 附录），逐项说明哪些必需、哪些可选
- **导言八要素**（§5.3.1）：现实性、研究程度、目的与任务、科学新颖性、理论与实践意义、方法论与方法、**提交答辩的论点**、**可靠程度与检验**
- 扉页八项（§5.1.2）：机构名、「На правах рукописи」、作者、题目、**专业代码与名称**、学位与学科门类、导师及学位职称、地点与年份
- 结论、各章小结的位置与写法
- 科学报告式论文的另一种结构（§6–7）

### 二、版式

| 参数 | 学位论文 | 卡死出处 |
|---|---|---|
| 纸张 | A4 210 × 297 mm，单面 | §5.3.6 |
| 页边距 | 左 25 / 右 10 / 上 20 / 下 20 mm | §5.3.7 |
| 字号 | 12–14 pt（区间，不是固定值） | §5.3.6 |
| 行距 | 1.5 倍 | §5.3.6 |
| 段首缩进 | 5 个字符 | §5.3.7 |
| 页码 | 上边距居中；扉页算第 1 页但不标号，第 2 页起标「2」 | §5.3.8 |
| 装订 | 硬封面 | §5.3.6 |

同一节还管：每章另起一页（§5.3.4）、标题居中且末尾不加点、不得移行、上下各隔三个行距（§5.3.5）、目录标题与正文一字不差并用 отточие 连页码（§5.2.3）。

> ⚠️ 本科 / 专家 / 硕士的 ВКР 用的是另一套参数（边距 30-15-20-20、缩进 1.25 cm）。技能里留了三行对照表，别混用。

### 三、图表公式

- 插图：放在首次引用处下方或次页，通编或章内编号，文中写「Рисунок N」
- 表格：表题在**表上方**，文中写「Таблица N」，**表清单须并入插图材料清单**
- 公式：符号用国标，释义紧随其后，编号圆括号右对齐
- 这三项的绘制细则均按 ГОСТ 2.105

### 四、文中引用（三套格式）

按 ГОСТ Р 7.0.5 附录 A：

1. **文中圆括号**：`(Мунин А. Н. Деловое общение… М.: Флинта, 2008. 374 с.)`
2. **脚注**
3. **文后编号**：`[10, с. 96]`；重复引用写 `(Там же, с. 54)`；不编号的 затекстовая 引用写作者姓 `[Михайловым С. А., Тепляковой С. А.]`

也说明**作者-年份式**（`[Изард 2008]`）——五篇实测里两篇用它，两篇用编号式，一篇混用，**没有主流**。用哪套取决于导师与期刊，不是规定。

### 五、文献表著录（12 个模板）

按 ГОСТ Р 7.0.100-2018：

书（1–3 作者 / 4 位以上 / 无作者 / 有编者）、电子书、期刊印刷版、期刊电子版、期刊带 DOI、文集、会议文集、词典条目、学位论文、автореферат、法规、光盘、在线资源、新闻稿。

附通用规则：分隔符用 en dash、作者姓后不加逗号、DOI 优先、非俄语文献单独排序在后、地名缩写（М. / СПб.）、页数 `с.` 与 `л.` 的区别。

> ⚠️ ГОСТ 7.0.11 **附录 Б** 里的样例是旧标准 ГОСТ 7.1-2003 的格式（姓后**有逗号**、用长破折号）。技能 §12.0 专门说明这个坑与「用哪一套」的判定。

### 六、автореферат（论文摘要）

- 封面 12 项要素（答辩日期时间、答委会编号、机构地址、寄送日期、学术秘书姓名等）
- 正文结构：总体特征八要素 + 各章内容 + 结论 + 作者论著清单
- 印刷份数由答辩委员会定

## 怎么用

直接说需求即可，技能靠 `description` 里的触发词自动激活：

```
按 ГОСТ 排一下这篇论文
核一下论文格式和 ГОСТ 对不上在哪
参考文献按 ГОСТ Р 7.0.100-2018 著录
文中引用该怎么写
帮我写 автореферат
```

触发词：`ГОСТ`、`диссертация`、`автореферат`、`список литературы`、`оформление диссертации`、`ссылки в тексте`、`学位论文格式`、`参考文献著录`。

典型任务链：

1. **新建**：给定题目与专业代码 → 生成扉页模板 + 骨架
2. **核查**：读入已有 .docx，逐项比对参数，输出「哪一项不对、依据哪条、改成什么」
3. **修版式**：批量改纸张、边距、页码、标题居中、分页符
4. **建目录**：从标题提取条目，按 §5.2.3 加 отточие 与页码
5. **理文献**：按 12 模板重排，处理中俄混排与非俄语排序

```
SKILL.md                          主文件，547 行 / 16 节
references/
  ├── автореферат.md              §8–9 全文展开，含封面 12 项
  ├── научный_доклад.md           §6–7 科学报告式论文
  └── таблицы_и_формулы.md        §5.3.9–5.3.11 图表公式
```

`SKILL.md` 按「适用范围 → 结构 → 版式 → 图表 → 引用 → 著录 → 摘要 → 报告式 → 双语规则 → 使用指南」排，每节标注条文号，可回溯到原文。

## 实测验证

用五篇 5.8.2 专业（Теория и методика обучения и воспитания）的真实学位论文做过交叉验证：

| 项 | 五篇实测 | 与技能 |
|---|---|---|
| 纸张 | 全部 A4 21.00 × 29.70 | ✅ 一致 |
| 字号 | 13.9 – 14.0 pt | ✅ 落在 12–14 区间 |
| 行距 | 24.0 – 24.2 pt = 1.5 倍 | ✅ 一致 |
| 页码 | 全部上边距居中 | ✅ 一致 |
| 扉页 | 全部第 1 页，带「На правах рукописи」 | ✅ 一致 |
| 目录 | 全部第 2 页，带 отточие | ✅ 一致 |
| 导言八要素 | 全部齐全 | ✅ 一致 |
| 左边距 | 2.50 / 3.00 / 2.54 两派 | ⚠️ 3.00 是留装订边 |
| 右边距 | 0.87 – 2.41 不等 | ⚠️ 无一严格 10 mm |
| 引用体例 | 作者-年份 2 : 编号 2 : 混合 1 | ⚠️ 无主流 |

**结论**：硬参数（纸张、字号、行距、页码、结构）五篇全一致；软参数（边距宽窄、引用体例）各家不同，技能只给条文值，不按「多数派的做法」改。

## 已知边界

1. **ГОСТ 2.105 与 ГОСТ Р 7.0.5 全文未取得**。技能里凡涉及这两份的地方只写「按 XXX 办理」，不用推测充标准。
2. **只管格式，不管内容**。论点是否站得住、文献是否读透、论证是否充分，不在这个技能的范围。
3. **不替代导师与答委会**。技能给的是可核查的条文依据，最终判断在人。
4. 边距 25/10 mm 的依据是 §5.3.7，但实测五篇里两篇用 30 mm 留装订边——**如果你的学校另有规定，按规定来，技能不是唯一答案**。
